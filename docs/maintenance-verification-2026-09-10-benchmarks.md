# 2026-09-10 检测效果与 DAST 基准维护核实

本记录说明 QA-001、QA-002 和 DAST-001 的本轮交付、真实结果、清理与保留边界。项目所有者要求先收尾已完成内容并停止当前阻塞扩展；因此没有继续引入第二个外部仓库或扩大所有 DAST 策略。

## 起点与根因

- 起点为干净 `main`，HEAD/origin 均为 `bca2cf5d8887c56d965cac8ba3107e0fc1a516e4`，领先/落后 `0/0`。
- 现有单元测试证明扫描代码行为，却没有固定标签、计算公式、阈值、差异清单和输入/报告哈希，不能据此宣称精确率或召回率。
- `testproject` README 有官方 30 项，但此前只有 Finding 数量和若干历史扫描摘要，没有逐项映射；不同问题还横跨 SAST、SCA、Git、代码质量和运行态验证。
- DAST 已有执行器和证据裁决，但没有把红/黄/绿/未验证、修复前/后目标和重复运行放进同一个版本化基准。

## 修改与通用性

- 新增 `security-minimal-v1`：SAST、AGENT 的正负样本和标签决策，SCA lodash 漏洞/修复版本对，以及 DAST 四态证据合同。脚本输出混淆矩阵、precision、recall、FPR、阈值失败、逐样本差异和输入哈希。
- 新增固定外部映射：校验 `vulnerable-node-api` 的 origin、干净工作区、提交和 README SHA-256，再将官方 30 项逐项映射到模块、通用规则、源码证据或未检原因。身份不一致时退出 3。
- 新增 DAST 成对实际重放：同一版本化 Python 目标以 vulnerable/safe 两种模式运行，固定本机 `python:3.12-slim` 镜像 ID，代码注入和安全配置各重复 3 次。容器只绑定 `127.0.0.1`，只读挂载目标，删除全部 capability，并限制内存、CPU 与进程数。
- 所有实现位于独立 benchmark、脚本和测试目录；没有修改生产扫描规则、扫描器编排、数据库、角色或前端。标签按规则 ID 与通用证据合同匹配，不含 `testproject` 路由、变量、固定行号或项目 ID 条件。

## 真实结果

- 内部 SAST：5 TP、0 FP、0 FN、5 TN；在这 5 个规则/2 个小样本内 precision/recall 为 1.0、FPR 为 0.0。
- 内部 AGENT：3 TP、0 FP、0 FN、3 TN；在这 3 个规则/2 个小样本内 precision/recall 为 1.0、FPR 为 0.0。
- 内部 SCA：lodash 成对样本的组件召回、漏洞 precision/recall 均为 1.0；仅代表 npm/lodash 与内置确定性规则。
- 合同 DAST：红/黄/绿/未验证各 3 次，4/4 案例裁决正确，12/12 一致，决定性证据完整率 1.0。
- 成对实际 DAST：漏洞/安全目标、代码注入/安全配置共 4 个案例，各 3 次；12/12 裁决正确、12/12 一致、12/12 证据完整。基准镜像 ID 为 `sha256:423ed6ab...199fbf`。
- 固定 `testproject` 官方清单：命中 15/30，即 50%；排除 6 个明确代码质量项后的安全范围为 15/24，即 62.5%。这不是通用召回率。
- `testproject` 实际 DAST：精确提交 `1f8fed3` 的只读源码在一次性、本机 Node 容器中运行；代码注入、命令注入、路径穿越、安全配置各重复 3 次，12/12 为 `exploitable`、一致且证据完整。由于项目无 lock 文件、容器启动时重新安装依赖，该结果不并入固定成对复现率。

内部 100% 只适用于当前很小的版本化语料，不是平台覆盖率。官方清单未覆盖项包括 Express 项目级缺失性规则、环境回退和链式响应语义、Git 索引基准、确定性 Express 漏洞情报，以及明确的代码质量项；本轮没有为了提高数字修改规则。

## 验证与清理

- 定向后端：`116 passed, 8 warnings`。
- 完整后端：D 盘专用临时目录中 `444 passed, 1 skipped, 34 warnings`；唯一跳过仍为当前 Windows 账号不能创建 symlink，告警仍为 32 条 `datetime.utcnow()` 和 2 条 FastAPI `on_event`。
- 前端没有业务代码变更；`npm run build` 和 `test:dev-server` 通过，日常 `http://127.0.0.1:5173` 返回 200。最大 JavaScript 包仍为 661.92 kB、gzip 190.51 kB并保留 Vite 告警。
- 合成 DAST 容器与 `testproject` 容器均已删除，对应临时端口无监听；`testproject` 仍是干净工作区和原提交。没有写入项目数据库、扫描任务、Finding、账号、会话、配置或目标记录。
- 完整 JSON/SARIF 类运行产物只写在 `.tmp/security-benchmark`，在提交前删除；可比较摘要、输入哈希和当次完整报告哈希保存在版本化 `baseline-summary.json`。
