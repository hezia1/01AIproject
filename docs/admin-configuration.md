分页范围为数据记录和重复证据列表，不把导航标签、表单字段、下拉选项、固定流程步骤拆成分页。分页总数是当前接口实际返回的数据量，不伪称数据库全部历史数量；后端已有有界扫描/历史查询范围不因此扩展，服务端大数据游标分页仍见 deferred-work。

## 使用位置与权限

- 管理中心 → SCA → 本地规则与门禁：新增/编辑漏洞、许可证与门禁策略。项目覆盖优先于平台覆盖；影响后续扫描，不重写历史扫描结论。
- 管理中心 → SAST → 本地规则：当前项目人工正则规则；Semgrep 规则：当前项目 YAML 包以及平台社区规则。内置扫描逻辑、项目自定义规则与社区规则是不同来源。
- 管理中心 → SCA → 本地漏洞资源，或 SAST → 联网下载策略：维护资源下载权限。
- 管理中心 → SANDBOX → 镜像白名单与联网：维护镜像仓库及镜像/依赖下载开关。
- 普通用户仍可切换/新增项目、接入模块、执行基本检测、使用 ASPM 与知识中枢；管理员允许时仍可人工更新 Grype 和 Semgrep。新增维护策略 PUT 接口在后端校验管理员，不能靠绕过前端修改。

## 配置存储与生效边界

`GET /api/admin/maintenance-policy` 向已登录用户返回有效配置与版本；`PUT` 仅管理员可用。配置存于 `platform_policies`，迁移版本 `20260904_0016`，保存写入现有 `audit_events`。并发更新通过事务锁和版本冲突检查防止覆盖；数据库不可用时不能回退成允许下载。API 与后台执行路径读取同一配置，不使用长期缓存。

默认开关为允许，镜像仓库默认保持此前集合。新配置不终止已经开始的操作。网页“添加到草稿/编辑”不生效，点击保存才写入；重新加载期间不能保存旧草稿。

- Grype、Semgrep 仍只在用户显式请求时更新；扫描不自动更新漏洞库/规则。Semgrep 许可证确认仍必需。
- SCA 检查/扫描 Docker 命令使用 `--pull=never`，不会因缺失工具镜像而隐式拉取。禁止 npm 依赖解析后沿用现有清单，并记录 `blocked`/降级原因，不冒充完整依赖扫描。
- SANDBOX 镜像白名单只接受 `node` 或 `organization/image` 形式，不接受通配符、标签、任意注册表地址或命令片段。拉取时镜像必须另带标签或 SHA-256 digest。它不是域名/外联地址白名单；已在本地准备的镜像保持原有使用方式。
- 禁止 SANDBOX 依赖联网后，准备容器使用 `--network none`；缓存/源码不足时明确失败。运行容器的内部网络、只读挂载、能力剥离和资源上限不变。
- `PLATFORM_OFFLINE_ONLY=true` 强制禁止上述下载及联网准备；`SCA_OFFLINE_ONLY=true` 还会禁止 SCA npm 联网解析与 Grype 更新，管理员允许不能覆盖显式离线限制。前者是维护下载限制，不是全平台网络防火墙。
- OSV 在线精确查询/整批离线回退、AI API、项目 Git 接入、外部 DAST 目标请求有各自既有逻辑，不由下载开关统一代理或阻断；不能把本页开关宣称为系统级断网。
