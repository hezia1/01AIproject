# 六模块现状与关系

更新日期：2026-08-28。六模块可以按项目启用、配置和执行，结果统一写入 PostgreSQL，并在项目级 ASPM 视图中汇总。模块注册表和前端文案必须只描述下列当前能力。

## SCA：供应链风险分析

**已实现**：npm、PyPI、Maven、Go、Bundler、Composer、Cargo、NuGet 常见清单/锁文件解析；直接与传递依赖；SBOM；许可证；本地规则、OSV/离线镜像、CVSS/EPSS/KEV 导入；VEX、例外、依赖图、扫描差异、JSON/SARIF 和质量门禁。

**有条件实现**：在线 OSV、Syft、Grype、Trivy 取决于网络、固定工具或离线镜像。缺失时保留本地解析结果并显示情报降级。

**边界**：尚无经过标注语料验证的漏洞准确率与生态兼容率；SCA Finding 当前不自动进入 DAST。

## SAST：智能静态审计

**已实现**：内置本地规则、项目规则包、Semgrep YAML 导入、有限数据流、Git 基线与历史密钥证据、规则治理、扫描差异、SARIF、修复草案，以及可选的七角色 AI 复核。

**有条件实现**：DeepSeek 复核需项目启用并提供密钥；Semgrep 需预置固定引擎和规则。每次 AI 运行可生成 `security_skill` 草案，知识关联以当前项目历史为主。

**边界**：这不是编译器级全程序分析；尚无可复用的企业定制 Skill 库、行业历史漏洞知识库或跨项目自动学习闭环。

## AGENT：Agent 供应链安全

**已实现**：扫描 Markdown Frontmatter、JSON、YAML、TOML 和常见 Agent/MCP/插件配置；识别指令、Prompt、Skill、MCP、工具和插件资产；归一化权限、资源、信任和差异；提供 CLI、SARIF、HTML 与门禁。

**有条件实现**：受控 Agent 运行时探针要求一次性 Docker 目标和目标侧证据合同。

**边界**：不会连接真实生产 MCP、调用真实副作用工具或推断未上报的运行时行为；私有源和公开报告能力不等于完整市场治理平台。

## DAST：有界动态验证

**已实现**：将受支持且上下文完整的 SAST/AGENT Finding 转成策略；支持审批、Dry Run、同源/路径/身份/请求预算限制、固定 HTTP 与浏览器探针、差分验证、证据归档、红黄绿裁决和专项报告。

**有条件实现**：需要可达的已授权目标，或由 SANDBOX 成功启动的一次性目标。文件上传、时延、浏览器和 Agent 运行时等专项探针各有独立证据门槛。

**边界**：当前源码到动态目标映射主要覆盖 EJS 和 JavaScript/TypeScript 文件族；不生成任意 PoC，不保证每个静态 Finding 都可动态验证。

## SANDBOX：隔离运行与证据采集

**已实现**：从项目文件推断受限启动计划；校验镜像、命令、端口、健康检查和辅助服务；在 Docker 内部网络中启动目标；执行固定 HTTP、浏览器、文件上传、时延和 Agent 合同探针；归档 HAR、截图、控制台、时延、事件和证据摘要。

**有条件实现**：需要 Docker Engine、白名单镜像和项目兼容的非 root/只读/受限网络运行方式。自动辅助服务目前只覆盖 PostgreSQL 与 Redis。

**边界**：不是完整的文件/网络/进程/环境变量/系统调用监控平台，不执行 AI 自主攻击，也不照搬项目 Compose 中的主机挂载、密钥和任意命令。

## ASPM：项目级治理与交付

**已实现**：单项目总览、模块结果汇总、显式证据关系图、攻击链、Finding 状态、整改与复测、动态证据回链和项目安全报告。

**边界**：尚无项目组、跨项目关联与组织趋势、授权配额、完整审计中心、SLA/工单、生产级合规报告、独立 CVSS/EPSS 计算模型或租户权限执行。CLI/CI 门禁属于各扫描模块，不应表述成 ASPM 已交付的统一流水线平台。

## 模块依赖

```text
SCA ───────────────┐
SAST ──► DAST ──┐  │
AGENT ─► DAST ──┼──┼──► ASPM（单项目治理）
                 │  │
          SANDBOX ──┘
```

- SCA、SAST、AGENT 可独立执行静态扫描。
- DAST 当前从 SAST/AGENT 获取候选，不从 SCA 获取候选。
- SANDBOX 为需要隔离目标的 DAST/Agent 验证提供运行环境和证据。
- ASPM 聚合事实，不改变扫描器结论，也不在证据不足时自动提升裁决。
