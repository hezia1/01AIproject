# 当前技术架构

更新日期：2026-09-09。本轮核实范围与运行证据见 [维护核实记录](maintenance-verification-2026-09-09.md)。

## 1. 架构结论

项目当前是面向单机研发与演示的模块化单体，不是微服务产品：

- React Web 控制台通过 REST 调用 FastAPI。
- Web 的 `AuthGate` 与 API 的 `AuthenticationMiddleware` 提供本地 `user` / `admin` 登录、数据库会话和管理员操作校验；模块与扫描配置另有字段级权限校验。
- FastAPI 路由负责协议和参数，扫描、验证、证据和报告逻辑集中在服务层。
- PostgreSQL 是项目、模块配置、扫描、组件、Finding、DAST、SANDBOX、知识条目/版本和治理数据的事实源。
- Alembic 管理数据库演进；当前仓库迁移头为 `20260909_0018`，已包含六模块实体、本地会话、平台维护策略、声明式 Skill 注册/版本/运行记录和扫描完成触发配置。本轮开发数据库已实际升级到该版本；其他环境仍需连接数据库核对，不能由迁移文件存在推断已经升级。
- `scripts/sast_worker.py` 轮询 PostgreSQL 中的 SAST 作业。Redis 随本地 Compose 启动，但尚未承担生产级分布式队列。
- Docker 只用于受控目标、辅助服务和固定执行器；项目自带命令、挂载、端口和密钥不会未经校验直接执行。
- 项目接入服务支持本地目录引用、受控 ZIP 解压和 HTTP(S) Git 浅克隆；受管副本位于 `PROJECT_IMPORT_ROOT`，项目删除时只清理该目录内对应分配，不删除用户本地源码。

## 3. 六模块数据流

1. 项目通过本地目录、受控 ZIP 或 HTTP(S) Git 接入，保存源码路径、仓库信息、运行地址和可选沙箱参数；资产盘点形成静态与动态模块准备度。
2. 快速模式以本地规则和文件/体积/软时限上限形成有界基础结果，SCA 仍会尝试在线 OSV 并在网络失败时整批回退本地镜像/规则；不覆盖用户明确启用的 SCA Docker 或 Semgrep。显式离线选项另行约束联网；深度模式取消快速范围上限，增强工具仍按项目配置执行。
3. SCA 解析依赖和离线/在线情报，生成组件、风险、SBOM、VEX 和门禁结果。
4. SAST 使用本地规则、项目规则、固定版本且按技术栈选择的本机 Semgrep 社区安全规则、有限数据流、Git 基线和可选 AI 复核生成代码 Finding；社区规则更新是用户确认许可证后的独立联网动作，扫描阶段不访问社区仓库或 Registry。已启用的外部 AI 复核仍会调用配置的模型 API。
5. AGENT 解析 Agent 指令、Prompt、Skill、MCP、工具和插件配置，生成资产、权限与信任证据。
6. 已发布的租户级 Skill 可由管理员选择在 SCA、SAST 或 AGENT 扫描成功提交后自动执行；它只按声明式条件复核该项目的当前 Finding，并按 Skill/扫描任务幂等记录结果。Skill 失败单独记录，不改写原扫描的成功状态。
7. DAST 只接收当前支持类型且上下文完整的 SAST/AGENT Finding，生成有界策略和待审批合同；SCA 风险当前不进入 DAST 队列。
8. 已上线目标由固定 HTTP/浏览器执行器验证；需隔离启动的目标由 SANDBOX 创建一次性 Docker 实例并采集证据。
9. 裁决服务只基于已归档证据产生红/黄/绿或“未验证”状态。
10. ASPM 在单项目范围汇总组件、Finding、动态验证、沙箱证据、整改与复测。
11. 知识中枢将当前 Finding 提交为项目候选；满足动态证据或治理结论门槛后，由管理员审核发布，并按来源项目的租户字段、相同规则或风险分类向其他项目推荐。

## 4. 执行与证据边界

- SANDBOX 采用内部网络、能力删除、只读根文件系统、非 root、资源限制和平台标签；其实现是隔离执行与固定探针，不是完整 EDR 或系统调用监控。
- DAST 只允许同源、审批路径、请求上限、身份引用和声明式步骤，不接受任意攻击脚本或 Shell。
- Agent 运行时红/绿裁决要求目标接入 `dast_runtime_evidence` 合同；仅有文本回显时保持黄色。
- AI 可生成候选、解释和修复草案，但不能代替证据裁决，也不会自动修改源码或提交代码。
- 知识候选按项目关联；已发布知识的推荐查询按来源项目的租户字段匹配。推荐不自动修改规则，提交、发布、退回和回滚均保存版本与审计事件；该查询约束不等于已完成请求级租户授权。
- 离线漏洞情报、固定镜像和模型密钥缺失时，相关能力会降级或阻塞，不得展示为完整执行。
- ZIP 导入拒绝路径穿越、符号链接、超限文件数和解压体积；Git 只接受 HTTP(S)，禁用交互式凭据和 URL 内嵌明文密码/令牌。
- 平台维护策略存入 `platform_policies`，API 与后台路径读取同一数据库配置，数据库错误不会转成允许下载；保存使用事务锁和版本冲突检查。管理员配置不会覆盖显式离线限制，具体下载边界见 [管理员配置说明](admin-configuration.md)。

## 5. 真实持久化模型

当前核心实体包括：租户/用户/成员关系与审计模型、项目、项目模块配置、扫描任务、组件、Finding、SCA 情报与 VEX、SAST 规则/基线/复核、Agent 资产与权限、DAST 策略/运行/证据/裁决、SANDBOX 目标/任务/事件/证据、知识条目/版本、Security Skill/不可变版本/运行记录，以及整改、复测和报告所需关系。

请求身份中间件已接入应用入口：除健康检查、认证状态、初始化、登录和注册等公开端点外，请求需有效本地会话，管理员操作另做角色检查。模块接入/更新和 SAST 单次扫描参数有独立配置边界。密码为 scrypt 哈希，`user_sessions` 保存令牌哈希及到期时间；Cookie 使用 HttpOnly / SameSite=Lax，当前 `secure=False`，仍是本地 HTTP 开发配置。

身份表和本地角色校验不等于生产租户隔离：项目创建仍落在默认本地租户，项目列表和多处按 ID 读取接口没有统一按请求身份过滤，项目成员授权尚未实施。知识审计的操作人仍来自请求字段；部分新接口已绑定后端会话身份，但未形成全平台统一、不可抵赖审计。`AUTH_DISABLED=true` 会显式绕过认证并注入测试管理员，只用于隔离测试，不是部署能力。`/api/health` 固定返回 `ok`，不能作为数据库、扫描器或外部工具健康的证明。
