# 当前技术架构

更新日期：2026-08-29。

## 1. 架构结论

项目当前是面向单机研发与演示的模块化单体，不是微服务产品：

- React Web 控制台通过 REST 调用 FastAPI。
- FastAPI 路由负责协议和参数，扫描、验证、证据和报告逻辑集中在服务层。
- PostgreSQL 是项目、模块配置、扫描、组件、Finding、DAST、SANDBOX、知识条目/版本和治理数据的事实源。
- Alembic 管理数据库演进；当前迁移链已覆盖六模块所需实体。
- `scripts/sast_worker.py` 轮询 PostgreSQL 中的 SAST 作业。Redis 随本地 Compose 启动，但尚未承担生产级分布式队列。
- Docker 只用于受控目标、辅助服务和固定执行器；项目自带命令、挂载、端口和密钥不会未经校验直接执行。
- 项目接入服务支持本地目录引用、受控 ZIP 解压和 HTTP(S) Git 浅克隆；受管副本位于 `PROJECT_IMPORT_ROOT`，项目删除时只清理该目录内对应分配，不删除用户本地源码。

## 2. 运行拓扑

```text
浏览器
  │
  ▼
React / Vite 控制台
  │ REST
  ▼
FastAPI 模块化单体
  ├── 项目导入、资产盘点、准备度与模块配置
  ├── SCA / SAST / AGENT 扫描服务
  ├── DAST 策略、审批、执行、裁决
  ├── SANDBOX 启动规划、Docker 编排、固定探针
  ├── ASPM 汇总、证据图、整改、复测、报告
  └── 知识中枢候选、审核、版本、回滚与跨项目推荐
  │
  ├── PostgreSQL 16：结构化事实和审计证据
  ├── 本地 artifacts：离线情报、可选工具产物和报告
  ├── Redis 7：基础设施预留，当前非核心任务总线
  └── Docker Engine：隔离目标、PostgreSQL/Redis、固定执行镜像
```

API 和 Web 尚无仓库内的生产部署编排；`infra/docker-compose.yml` 只启动 PostgreSQL 与 Redis。

## 3. 六模块数据流

1. 项目通过本地目录、受控 ZIP 或 HTTP(S) Git 接入，保存源码路径、仓库信息、运行地址和可选沙箱参数；资产盘点形成静态与动态模块准备度。
2. 快速模式以本地规则、离线情报、文件/体积/软时限上限形成有界结果；深度模式才启用增强工具和外部依赖。
3. SCA 解析依赖和离线/在线情报，生成组件、风险、SBOM、VEX 和门禁结果。
4. SAST 使用本地规则、项目规则、有限数据流、Git 基线和可选 AI 复核生成代码 Finding。
5. AGENT 解析 Agent 指令、Prompt、Skill、MCP、工具和插件配置，生成资产、权限与信任证据。
6. DAST 只接收当前支持类型且上下文完整的 SAST/AGENT Finding，生成有界策略和待审批合同；SCA 风险当前不进入 DAST 队列。
7. 已上线目标由固定 HTTP/浏览器执行器验证；需隔离启动的目标由 SANDBOX 创建一次性 Docker 实例并采集证据。
8. 裁决服务只基于已归档证据产生红/黄/绿或“未验证”状态。
9. ASPM 在单项目范围汇总组件、Finding、动态验证、沙箱证据、整改与复测。
10. 知识中枢将当前 Finding 提交为项目候选；满足动态证据或治理结论门槛后，可由人工审核发布为租户级知识，并按相同规则或风险分类向其他项目推荐。

## 4. 执行与证据边界

- SANDBOX 采用内部网络、能力删除、只读根文件系统、非 root、资源限制和平台标签；其实现是隔离执行与固定探针，不是完整 EDR 或系统调用监控。
- DAST 只允许同源、审批路径、请求上限、身份引用和声明式步骤，不接受任意攻击脚本或 Shell。
- Agent 运行时红/绿裁决要求目标接入 `dast_runtime_evidence` 合同；仅有文本回显时保持黄色。
- AI 可生成候选、解释和修复草案，但不能代替证据裁决，也不会自动修改源码或提交代码。
- 知识候选按项目隔离；已发布知识只在同一租户内共享。推荐不自动修改规则，提交、发布、退回和回滚均保存版本与审计事件。
- 离线漏洞情报、固定镜像和模型密钥缺失时，相关能力会降级或阻塞，不得展示为完整执行。
- ZIP 导入拒绝路径穿越、符号链接、超限文件数和解压体积；Git 只接受 HTTP(S)，禁用交互式凭据和 URL 内嵌明文密码/令牌。

## 5. 真实持久化模型

当前核心实体包括：租户/用户/成员关系与审计模型、项目、项目模块配置、扫描任务、组件、Finding、SCA 情报与 VEX、SAST 规则/基线/复核、Agent 资产与权限、DAST 策略/运行/证据/裁决、SANDBOX 目标/任务/事件/证据、知识条目/版本，以及整改、复测和报告所需关系。

虽然数据库存在身份与租户相关模型，应用入口尚未设置可用的请求身份中间件，大部分接口仍运行在默认开发租户下。因此这些表结构不能被描述成已交付的登录、授权或租户隔离。
